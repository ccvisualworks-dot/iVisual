A FEW HELPFUL ANSWERS

Before you
make your pick.

A little clarity for your next step.

What is included in a template?+

Basic, Standard and Professional group the collection by design style and price. Each option is a responsive, one-page HTML, CSS, and JavaScript design with the sections listed in its details. The live demos include sample content and an enquiry form demonstration. A template does not include a domain, hosting, content customisation, a working enquiry inbox, or an online shop backend.

Can I try every template first?+

Yes. Select Live preview to explore the actual page. Use the Desktop and Mobile controls to check its layout, then return to this shop or choose it directly from the preview.

Can I pay or receive files now?+

This is a shop preview. Prices are examples for review. You can try the order flow and save a demo order in this browser, but no money is collected, no order is sent, and no template download is fulfilled. Real checkout and delivery will be enabled after the shop owner's approval.

Can the design be customised?+

The template is a starting point. Colours, text, and images can be changed in its source files. Content setup, new sections, domain setup, and other services can be agreed separately before any purchase.
